# FoodBot

Автоматизация готовки "стейка с фруктовым соусом и рисом" для GTA 5 RP. Windows, без установки Python.

## Запуск
1. Открой `Releases` и скачай `FoodBot.exe` (Windows 10/11 64-bit).
2. Поставь игру в оконный режим без рамки, масштаб Windows 100%.
3. Запусти `FoodBot.exe`, выбери блюдо, введи количество, игра должна быть активна.
4. Остановка — кнопка «Стоп» или `Esc`.

Если `Esc` не ловит в игре — запусти EXE от администратора.

## Важно
- Координаты кликов настроены под конкретное разрешение/раскладку (1920 на 1080). Если у тебя другой экран — клики могут не попадать.
- Использование макросов может нарушать правила конкретных RAGE-серверов. Используй на свой риск.

## Состав
- `Releases/FoodBot.exe` — готовая программа, исходного Python-кода здесь нет.
